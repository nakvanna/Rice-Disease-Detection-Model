# Project Guideline
## Dataset
The first step download the dataset from kaggle and extract it in root of project.

[Kaggle]("https://www.kaggle.com/datasets/lyyheng/rice-leaf-dataset-in-cambodia")

## Run each notebook follow the order
1. Run `1_dataset_exploration.ipynb` to check any error and config it.

2. Run `2_preprocessing.ipynb` to preprocess the dataset.

3. Run `3_splittig_dataset.ipynb` to splitting the dataset into training, validating, and testing.

4. Run `4_pca_and_logistic_regression.ipynb` to reduce the dimensional by PCA and train it with Logistic Regression Model.

5. Run `5_pca_and_neural_network.ipynb` to reduce the dimensional by PCA and train it with Neural Network.

6. Run `6_pca_and_lr_and_nn.ipynb` to experiment and Evaluate both models and plot the virsualization.
